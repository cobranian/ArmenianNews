# L'espagnol, septième langue — plan de construction

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Servir armenianews.org/es/ (accueil, radio, eventos, acerca-de) entièrement en espagnol, avec un fil à quatre sources, une brève quotidienne espagnole et les événements argentins de Diario Armenia dans l'agenda.

**Architecture:** `es` devient une langue de plein droit dans `sites.config.js` (`ALL_LANGS`, page `/es/` du .org) ; tout le reste (hreflang, sitemaps, prérendu, 404) en dérive. Le contenu `es` a son PROPRE fil (pas de `CONTENT_LANG.es`) : trois nouveaux modules dans `scripts/sources/` plus l'édition `es` d'Armenpress. Diario Armenia alimente aussi `agenda.json` (`world`).

**Tech Stack:** Node ESM (`node --test`), Vite + React, cheerio, WordPress REST, RSS.

**Spec:** `docs/superpowers/specs/2026-10-31-espagnol-design.md` — à lire avant toute tâche. Lire aussi `CLAUDE.md`, et le skill `toucher-une-source` avant les tâches 4 à 8.

## Global Constraints

- Espagnol **latino-américain neutre** partout (ustedes, pas de voseo, pas de lunfardo), y compris dans chaque consigne envoyée à un modèle.
- Slugs : `/es/`, `/es/radio/`, `/es/eventos/`, `/es/acerca-de/`, brève `/es/resumen/`, Culture `/es/cultura/` — slash final compris.
- `LANGS` : `{ code: 'es', label: 'ES', name: 'Español' }` ; `LANG_SWITCH_LABEL.es = 'Idioma'` ; `OG_LOCALE.es = 'es_419'` ; `PRELOAD.es = PRELOAD.fr`.
- Culture : `es` dans `OPTIONAL` (jamais `REQUIRED`).
- Aucun nom de liste Buttondown pour `es` (`newsletter.lists.es` absent) tant que l'utilisateur n'a pas créé le compte.
- Rien dans `scripts/lib/social.mjs` (réseaux espagnols : hors chantier).
- User-Agent jamais « Chrome » (`scripts/lib/http.mjs`).
- Un champ non trouvé est **absent**, jamais deviné : un événement sans date sûre est écarté.
- Dates d'agenda en heure murale sans fuseau (`2026-11-08T19:00`), jamais de `Z`.
- `STALE_HOURS['armenpress/es'] = 96`.
- Lint : toujours 0 erreur, 5 avertissements.
- Travailler dans un worktree isolé (`superpowers:using-git-worktrees`), un commit par tâche (point de retour).

## Review Focus

1. **Un billet de Nor Sevan en arménien occidental** doit atterrir sous `hy`, jamais sous `es` — test dans la tâche 7.
2. **Une image Diario Armenia vue depuis armenianews.org** doit être la photo et non la vignette 200×200 : l'URL servie est `/da/<nom>`, jamais l'hôte d'origine — test dans la tâche 6.
3. **Une brève espagnole écrite en anglais ou en français** doit être écartée, et une brève espagnole correcte (« también », « está », « sur ») ne doit pas l'être — tests dans la tâche 3.
4. **Une annonce d'agenda sans date lisible** (« próximamente », date sans jour) est écartée, et « sábado 8 de noviembre a las 19 hs » donne `2026-11-08T19:00` — tests dans la tâche 8.
5. **Un lundi matin après un week-end sans Armenpress es** ne doit pas ouvrir `[sources-down]` — test dans la tâche 4.
